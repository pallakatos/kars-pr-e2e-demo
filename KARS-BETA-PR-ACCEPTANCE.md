# Kars Native GitHub Publication Acceptance

This document records acceptance of one narrowly scoped, reviewed publication path for Kars: creating a documentation-only pull request in `pallakatos/kars-pr-e2e-demo` through the native `github-pr` adapter.

## Accepted scope

- Inspect this exact path before publication and proceed only when it is absent.
- Create this single new Markdown file from the inspected base revision.
- Use one adapter-generated branch and open one pull request in the same repository.
- Leave the default branch unchanged and require separate human review and merge decisions.

## Explicit limits

This acceptance does **not** establish full beta readiness. It does not validate merging, direct default-branch writes, workflow changes, edits to existing files, arbitrary repository access, or general-purpose GitHub operations. Those capabilities remain outside this acceptance and require their own review and evidence.
