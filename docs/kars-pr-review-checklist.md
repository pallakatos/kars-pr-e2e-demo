# PR Review Checklist

Use this checklist before merging this pull request.

- [ ] Review the changed paths and confirm only the intended documentation file was modified.
- [ ] Review the full diff for accuracy, clarity, and scope.
- [ ] Confirm the reported check results are based only on checks actually observed on the PR.
- [ ] If no CI or status checks are visible, record that CI status is unknown rather than assuming success.
- [ ] Do not merge until a human reviewer explicitly approves it.
